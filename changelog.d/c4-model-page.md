- **C4 model page** (c4-model-page, issue #71). A new `c4-model-page` skill builds one self-contained HTML page per feature, with Context, Containers, Calls, Run and Changes tabs and Mermaid diagrams you can pan, zoom and show full screen. It reads the plugin's own documents by default (`design.md`, `architecture-overview.md`, `openapi.yaml`, `workspace.dsl`); a team can name its own technical design, overview or per-repo `openapi.yaml` instead. `check.mjs` checks that every call is an arrow and every changed system is coloured as its change. Design hands off to it before its gate. Test in `tests/c4-model-page.test.mjs`.
