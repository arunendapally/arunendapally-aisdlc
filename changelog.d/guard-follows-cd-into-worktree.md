- **Fixed: a commit in a nested worktree is judged on its own branch** (guard-follows-cd-into-worktree). A command that starts with `cd` into a worktree under the main checkout (`.claude/worktrees/<slug>`) was judged on the main checkout's branch, so a session or subagent whose folder was the main checkout was refused every commit there as "You are on main". The guard now judges the branch of the worktree the `cd` enters; the main checkout and its own folders stay protected. Test in `tests/guard-follows-cd-into-worktree.test.mjs`.
