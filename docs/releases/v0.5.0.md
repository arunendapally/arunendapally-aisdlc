# v0.5.0: questions instead of commands, and autonomy when you want it

You no longer type or paste commands: the plugin asks you, and you click. A repo can be handed to agents end to end when you say so. And the process was run on a real feature from an empty folder, which found 25 places it got in the way; most are fixed here.

## Update

```bash
claude plugin marketplace update arunendapally-aisdlc
```

```bash
claude plugin update ai-sdlc@arunendapally-aisdlc
```

Then start a new Claude Code session.

## What changes for you

- **The plugin asks; you click.** For your intent and at every gate, the agent asks a short multiple-choice question: Approve, or Send back with your reason; for the intent, change, smallest version and what would make you drop it, with answers drawn from what you already said. Your click is recorded with the same checks as a typed command; an agent cannot answer for you. Typing `sdlc approve` still works.
- **Autonomy, when you choose it.** `sdlc autonomy on <why>` hands a repo to agents: every gate passes on its checks, recorded as granted by you, and `sdlc merge` lands the reviewed commit. `sdlc autonomy off` takes it back. The guards stay either way.
- **A late change request makes a v2.** An approved spec or design that changes comes back as v2, says what changed since v1, and the question shows it.
- **Fewer pointless refusals.** Tests and project files no longer count toward PR size; a review fix gets room; the guard judges the repo you are working in and stopped mistaking .NET's `appsettings.json` for its own settings; a new repo can be started; .NET and Java tests are recognised everywhere.
- **Earlier warnings.** A spec bigger than one slice is flagged at Plan, not after the code is written; `status` shows why a request was refused.
- **Knowledge in an open format.** Knowledge pages follow the Open Knowledge Format v0.2; old pages still work.

## Proven

- 151 tests and 29 golden evals pass; the evals catch all five recorded failures (F1 to F5).
- A scientific calculator (.NET minimal API and React) was taken from an empty folder to Verify through the plugin with no person at the gates. Its 25 findings are in [docs/feedback/2026-10-29-calculator-run.md](https://github.com/arunendapally/arunendapally-aisdlc/blob/main/docs/feedback/2026-10-29-calculator-run.md).

## Known limitations

- The question flow has not yet run in a live desktop session (headless runs have no question tool); the first gate question you see is its live check. If it records nothing, typing the command still works, and please open an issue.
- The calculator stopped at Verify, 5 lines over the light lane limit with code written before the size fixes; merge and Release under autonomy are covered by tests only.
- Open findings: greenfield notes for the baseline and the proof, reading plugin state outside the CLI, adding a scenario for an existing requirement, and review ledger locations that go stale.
- The agent evals (`npm run eval:agents`) were not rerun for this release.

The autopilot mod is 0.2.1 (it reads the new `knowledge/index.md`). Full list: [CHANGELOG.md](https://github.com/arunendapally/arunendapally-aisdlc/blob/main/CHANGELOG.md).
