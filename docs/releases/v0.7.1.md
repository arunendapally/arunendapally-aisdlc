# v0.7.1: bypass mode means no guard stops the session

- **In Claude Code's bypassPermissions mode, the plugin's guards no longer refuse or ask.** Each call they would have stopped is logged to `.ai-sdlc/audit.jsonl` as `bypassed`, so the PR review sees it, and it never holds the session. A human pause (`sdlc pause`) still stops a bypass session. Every other mode keeps every guard. Decision: ADR-0006. PR #49.

Update: `claude plugin marketplace update arunendapally-aisdlc`, then `claude plugin update ai-sdlc@arunendapally-aisdlc`, then start a new session.
